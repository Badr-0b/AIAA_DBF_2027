# Sources

Every source behind a number in this repository, with its link. Generated by `python analysis/data/sources_index.py` on 2026-10-14; do not edit by hand.

- **Primary sources only** for values: the publisher of a document is the authority for it. Retail-only data is marked RESELLER and never decides anything.
- **Nature:** MEASURED (a test or observation), SPEC (a manufacturer's rating or statement), COMPUTED (a model's output, e.g. APC's propeller tables), RULE, METHOD (an equation or tool), CONSULTED (read, no value used).
- **Re-checkable:** files the analysis read are hashed (SHA-256, first 12 characters shown; full hashes in `analysis/data/sources.lock` and `analysis/data/prop/sources.lock`). Every quoted value is checked against the cached file by `analysis/data/verify.py` and `analysis/data/prop/verify_prop.py`.
- **Values used:** how many verified values each source supplies to the analysis datasets.
