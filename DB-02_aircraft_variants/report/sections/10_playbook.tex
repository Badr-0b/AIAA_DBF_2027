\subsection{Decide each number when it can be decided well}
The largest single gain in this dossier came from timing, not hardware: choosing the declared sensor mass in April instead of now. The same discipline applies to every number the team must fix.

\subsection{Mission-day playbook}
\begin{itemize}
\item \textbf{Mission 1.} Waive it at the flight line. The first successful Mission~2 scores it.
\item \textbf{Mission 2.} Fly one unit at the declared mass. Add a simulator only if the weigh-in left margin and the afternoon is cool; the hot-day plan already sets the declared mass so that one unit is safe on the hottest likely afternoon.
\item \textbf{Mission 3.} Deploy before the first downwind turn with lights off, step the sequence with one button after laps one and two, and choose the ballast so the stow fits inside the window: a lighter dart that keeps the seventh lap beats a heavier one that loses it, and an 8~kg dart always loses it.
\item \textbf{Ground Mission.} Declare 1.524~m. Re-cut pads only at technical inspection, never on the day.
\item \textbf{Wind.} Above about 8~m/s sustained (the 90th percentile at TIMPA), fly the lighter Mission~3 ballast and land with full flap into wind.
\end{itemize}
